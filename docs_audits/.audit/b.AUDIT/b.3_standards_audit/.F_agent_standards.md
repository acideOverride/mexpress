## Version Control
- Document Version: 1.0
- Last Updated: 2025-02-14
- Status: Locked (Change Control Required)
- Change Process: See Change Control section

## Change Control
Changes to these standards require:
1. Formal change request
2. Impact analysis
3. Version update
4. Documentation update
5. Team notification

## Known Deviations
1. ARCHITECT:
   - Enhanced responsibilities list implemented
   - Additional quality gates added
   - Header formats standardized

2. ASK:
   - Enhanced responsibilities list implemented
   - Specific monitoring points added
   - Required actions defined

All other agents are fully compliant with no deviations.

## 1. Core File Structure

Each agent must maintain exactly three core files with standardized structures:

### 1.1 .clinerules File
```yaml
# Standard Structure for .clinerules
mode: [agent-name]
description: "[agent] focused operations"
version: "1.0.0"

# Core Focus Areas
responsibilities:
  - [List of primary responsibilities]

# Documentation Configuration
docs_path: /opt/mExpress/docs/[agent-type]/

# Required Documents (standardized across agents)
required_documents:
  implementation:
    path: [agent]-implementation.md
    sections: [standard sections]
  workflow:
    path: [agent]-workflow.md
    sections: [standard sections]

# Tool Groups (based on agent role)
allowed_tools:
  - read
  - [other tool groups as needed]

# Vocabulary Control (standardized terms)
terminology:
  required_terms: []
  prohibited_terms: []
```

### 1.2 role.md File
```markdown
# [Agent Name] Role Definition

## Primary Purpose
[Clear, single-sentence purpose]

## Core Responsibilities
1. [Primary responsibility]
2. [Secondary responsibility]
3. [Additional responsibilities]

## Workflow Position
- Reports to: [upstream agent]
- Handoff to: [downstream agent]
- QA Gates: [relevant QA checkpoints]

## Required Capabilities
1. [Core capability]
2. [Additional capabilities]

## Standard Operating Procedures
1. Input Processing
2. Quality Verification
3. Handoff Protocol
4. Error Handling
```
