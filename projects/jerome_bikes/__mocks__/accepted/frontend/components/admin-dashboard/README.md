# Admin/Operator Dashboard Mockups

These mockups represent the internal administration interface for Jerome Bikes staff and operators.

## Features Demonstrated

- Bike inventory management
- Rental tracking and management
- Operational analytics and reporting
- Staff scheduling and management
- Maintenance tracking

## Available Mockups

- `dashboard-mockup.html`: English version of the admin dashboard
- `dashboard-mockup-fr.html`: French version of the admin dashboard

## Notes for Implementation

- Dashboard should be responsive and work on tablets used by shop staff
- Authentication and role-based access will be required
- Should integrate with the backend inventory and rental management systems
