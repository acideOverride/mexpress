# Admin Bike Listing Components

These components display bike inventory listings in the admin interface.

## Purpose
- Provide administrators with a comprehensive view of all bike inventory
- Enable filtering, sorting, and searching through the bike fleet
- Support inventory management tasks like adding, removing, or updating bikes
- Present status information such as availability, maintenance needs, etc.

## Features
- Advanced filtering and search capabilities
- Bulk action support (update status, schedule maintenance, etc.)
- Sortable columns for inventory management
- Status indicators for maintenance, rental status, etc.
- Links to detailed bike information

## Available Mockups
- `bikes-listing.html`: English version of the admin bike listing
- `bikes-listing-fr.html`: French version of the admin bike listing
- `bikes-listing.js`: JavaScript for interactive listing functionality
