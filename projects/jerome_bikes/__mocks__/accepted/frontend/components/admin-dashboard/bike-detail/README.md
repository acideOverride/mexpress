# Admin Bike Detail Components

These components display detailed bike information in the admin interface.

## Purpose
- Allow administrators to view and edit detailed bike specifications
- Provide maintenance history and status information
- Track inventory details like purchase date, cost, and depreciation
- Display rental history and revenue generation for specific bikes

## Features
- Editable fields for bike specifications and status
- Maintenance scheduling and history tracking
- Inventory and asset management integration
- Links to related bookings and customer information
