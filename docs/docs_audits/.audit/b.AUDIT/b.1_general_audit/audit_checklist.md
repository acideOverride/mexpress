## 5. Audit Process

### 5.1 File Review Sequence
1. Start with template_v3.md
   - Document all workflows
   - Note message formats
   - List state management rules
   - Capture error handling

2. Cross-reference with role.md
   - Verify responsibilities
   - Check permissions
   - Validate documentation
   - Confirm state rules

3. Verify .clinerules implementation
   - Check configuration
   - Verify permissions
   - Validate workflows
   - Confirm state management
