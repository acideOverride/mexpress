# µF Agent Standards Audit Methodology

## 1. Preparation Phase
### 1.1 Core Files Location
- Access in .audit/a.PREPARATION/1.current_state:
  * template_v3.md
  * role.md
  * .clinerules
- Map file relationships
- Note initial patterns

### 1.2 Extraction Setup
- Review extraction prompt
- Prepare pattern templates
- Set up pattern tracking
- Define pattern categories

## 2. Pattern Extraction Phase
### 2.1 XML Pattern Extraction
1. Core Configuration
   - Identity blocks
   - Workspace definitions
   - State management
   - Tool interactions
   - Error handling

2. Integration Points
   - Chain connections
   - Mode transitions
   - Tool mappings
   - State preservation

### 2.2 Role Pattern Extraction
1. Task Management
   - Header formats
   - Protocol structures
   - Workflow patterns
   - State handling

2. Integration Elements
   - Chain positions
   - Handoff formats
   - Communication structures
   - State transitions

### 2.3 Rules Pattern Extraction
1. Configuration
   - Structure formats
   - Permission patterns
   - Parameter definitions
   - Mode rules

2. Integration Settings
   - Path definitions
   - Tool access
   - State management
   - Error handling

## 3. Pattern Analysis Phase
### 3.1 Pattern Categorization
- Group similar patterns
- Note variations
- Identify common elements
- Flag unique requirements

### 3.2 Pattern Relationships
- Map dependencies
- Track interactions
- Document flows
- Note constraints

## 4. Documentation Phase
### 4.1 Pattern Documentation
- Create in b.3_standards_audit:
  * [agent]_patterns.md with:
    - Extracted patterns
    - Pattern variations
    - Integration points
    - Standardization potential

### 4.2 Pattern Organization
- Group by type:
  * XML patterns
  * Role patterns
  * Rules patterns
  * Integration patterns
  * Unique patterns

## 5. Validation Phase
### 5.1 Pattern Review
- Verify extraction completeness
- Check pattern relationships
- Validate integration points
- Confirm variations

### 5.2 Next Steps
- Note standardization opportunities
- Flag pattern conflicts
- Identify consolidation points
- Mark unique requirements
