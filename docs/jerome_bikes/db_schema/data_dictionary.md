# Jerome Bikes Data Dictionary

This document describes the data models and fields used in the Jerome Bikes application.

## User Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| email | String | User's email address | Required, unique, valid email format |
| password | String | Bcrypt hashed password | Required, minimum 8 characters, stored in hashed format |
| firstName | String | User's first name | Required, trimmed |
| lastName | String | User's last name | Required, trimmed |
| role | String | User's role in the system | Required, must be one of: 'customer', 'admin', 'staff', 'maintenance' |
| isActive | Boolean | Whether the user account is active | Default: true |
| lastLogin | Date | Timestamp of last login | Optional |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

## Customer Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| userId | ObjectId | Reference to User model | Required, must exist in Users collection |
| phone | String | Customer's phone number | Required, trimmed |
| address | Object | Customer's address information | Optional |
| address.street | String | Street address | Required if address is provided |
| address.city | String | City | Required if address is provided |
| address.state | String | State or province | Required if address is provided |
| address.postalCode | String | Postal or ZIP code | Required if address is provided |
| address.country | String | Country | Required if address is provided |
| dateOfBirth | Date | Customer's date of birth | Optional |
| emergencyContact | Object | Emergency contact information | Optional |
| emergencyContact.name | String | Emergency contact name | Required if emergencyContact is provided |
| emergencyContact.phone | String | Emergency contact phone | Required if emergencyContact is provided |
| emergencyContact.relationship | String | Relationship to customer | Required if emergencyContact is provided |
| preferences | Object | Customer preferences | Optional |
| preferences.bikeTypes | Array[String] | Preferred bike types | Optional |
| preferences.bikeSize | String | Preferred bike size | Optional |
| preferences.notificationPreferences | Object | Notification settings | Optional |
| preferences.notificationPreferences.email | Boolean | Email notifications enabled | Default: true |
| preferences.notificationPreferences.sms | Boolean | SMS notifications enabled | Default: false |
| preferences.notificationPreferences.push | Boolean | Push notifications enabled | Default: false |
| paymentMethods | Array[Object] | Stored payment methods | Optional |
| paymentMethods[].type | String | Type of payment method | Required |
| paymentMethods[].lastFour | String | Last four digits of card | Required, must be 4 digits |
| paymentMethods[].expiryDate | String | Expiration date | Required, format: MM/YY |
| paymentMethods[].isDefault | Boolean | Whether this is the default payment method | Default: false |
| loyaltyPoints | Number | Accumulated loyalty points | Default: 0, minimum: 0 |
| memberSince | Date | Date the customer joined | Default: current date |
| rentalHistory | Array[ObjectId] | References to past reservations | Default: empty array |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

## Bike Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| name | String | Bike name or model | Required, trimmed |
| type | String | Type of bike | Required, must be one of: 'mountain', 'road', 'hybrid', 'electric', 'city', 'kids' |
| size | String | Size of the bike | Required, must be one of: 'xs', 's', 'm', 'l', 'xl' |
| modelYear | Number | Year of the bike model | Required, between 1900 and current year + 1 |
| color | String | Color of the bike | Required, trimmed |
| description | String | Description of the bike | Required, trimmed |
| frameNumber | String | Unique frame/serial number | Required, unique, trimmed |
| features | Array[String] | Special features of the bike | Default: empty array |
| specifications | Object | Technical specifications | Optional |
| specifications.weight | Number | Weight in kg | Optional, minimum: 0 |
| specifications.frameType | String | Type of frame | Optional |
| specifications.suspension | String | Suspension details | Optional |
| specifications.gears | Number | Number of gears | Optional, minimum: 0 |
| specifications.brakeType | String | Type of brakes | Optional |
| specifications.wheelSize | Number | Wheel size in inches | Optional, minimum: 0 |
| specifications.electricRange | Number | Range in km (for electric bikes) | Optional, minimum: 0 |
| dailyRate | Number | Cost per day | Required, minimum: 0 |
| hourlyRate | Number | Cost per hour | Required, minimum: 0 |
| weeklyRate | Number | Cost per week | Required, minimum: 0 |
| status | String | Current status of the bike | Required, must be one of: 'available', 'rented', 'maintenance', 'reserved', 'damaged', 'retired' |
| condition | String | Current condition description | Required, trimmed |
| maintenanceHistory | Array[ObjectId] | References to maintenance records | Default: empty array |
| currentLocation | ObjectId | Reference to current station | Required, must exist in Stations collection |
| imageUrls | Array[String] | URLs to bike images | Default: empty array |
| purchaseDate | Date | When the bike was purchased | Optional |
| purchasePrice | Number | Original purchase price | Optional, minimum: 0 |
| mileage | Number | Total distance traveled | Default: 0, minimum: 0 |
| ratings | Array[Object] | Customer ratings | Default: empty array |
| ratings[].userId | ObjectId | User who left the rating | Required |
| ratings[].rating | Number | Rating value (1-5) | Required, between 1 and 5 |
| ratings[].comment | String | Rating comment | Optional |
| ratings[].date | Date | Date of the rating | Default: current date |
| totalRentals | Number | Number of times rented | Default: 0, minimum: 0 |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

## Station Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| name | String | Station name | Required, trimmed |
| address | Object | Station address | Required |
| address.street | String | Street address | Required, trimmed |
| address.city | String | City | Required, trimmed |
| address.state | String | State or province | Required, trimmed |
| address.postalCode | String | Postal or ZIP code | Required, trimmed |
| address.country | String | Country | Required, trimmed |
| location | Object | GeoJSON point | Required |
| location.type | String | GeoJSON type | Required, must be 'Point' |
| location.coordinates | Array[Number] | [longitude, latitude] | Required, must be valid coordinates |
| capacity | Number | Maximum number of bikes | Required, minimum: 1 |
| currentBikes | Array[ObjectId] | Bikes currently at this station | Default: empty array |
| status | String | Operational status of the station | Required, must be one of: 'active', 'inactive', 'maintenance' |
| amenities | Array[String] | Available amenities | Default: empty array |
| openingHours | Object | Operating hours by day | Required |
| openingHours.monday | Object | Monday hours | Required |
| openingHours.monday.open | String | Opening time (HH:MM) | Required |
| openingHours.monday.close | String | Closing time (HH:MM) | Required |
| openingHours.[day] | Object | Hours for other days of week | Required for each day |
| contactPhone | String | Contact phone number | Optional |
| isAccessControlled | Boolean | Whether access is restricted | Default: false |
| accessMethod | String | Method for controlled access | Optional |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

## Reservation Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| customerId | ObjectId | Reference to Customer model | Required, must exist in Customers collection |
| bikes | Array[ObjectId] | References to reserved bikes | Required, must have at least one bike |
| startStation | ObjectId | Where bikes will be picked up | Required, must exist in Stations collection |
| endStation | ObjectId | Where bikes will be returned | Optional, must exist in Stations collection if provided |
| startDate | Date | Start of reservation period | Required, must be in the future |
| endDate | Date | End of reservation period | Required, must be after startDate |
| status | String | Current reservation status | Required, must be one of: 'pending', 'confirmed', 'active', 'completed', 'cancelled', 'no-show' |
| totalAmount | Number | Total cost of reservation | Required, minimum: 0 |
| paymentStatus | String | Payment status | Required, must be one of: 'pending', 'paid', 'refunded', 'partial' |
| discountCode | String | Applied discount code | Optional |
| discountAmount | Number | Amount of discount | Optional, minimum: 0 |
| createdBy | ObjectId | User who created the reservation | Required, must exist in Users collection |
| notes | String | Additional notes | Optional |
| weatherConditions | Object | Weather forecast for rental period | Optional |
| weatherConditions.forecast | String | Weather description | Optional |
| weatherConditions.temperature | Number | Temperature in degrees | Optional |
| weatherConditions.precipitation | Number | Precipitation percentage | Optional, between 0 and 100 |
| additionalServices | Array[Object] | Extra services booked | Optional |
| additionalServices[].name | String | Service name | Required |
| additionalServices[].price | Number | Service price | Required, minimum: 0 |
| additionalServices[].quantity | Number | Quantity of service | Required, minimum: 1 |
| specialRequirements | String | Special customer requests | Optional |
| insurance | Object | Insurance details | Optional |
| insurance.type | String | Type of insurance | Required if insurance is provided |
| insurance.coverageAmount | Number | Coverage amount | Required if insurance is provided, minimum: 0 |
| insurance.price | Number | Insurance cost | Required if insurance is provided, minimum: 0 |
| returnDetails | Object | Details of bike return | Optional, required for completed reservations |
| returnDetails.actualReturnDate | Date | When bikes were actually returned | Required if returnDetails is provided |
| returnDetails.condition | String | Condition upon return | Required if returnDetails is provided |
| returnDetails.additionalCharges | Number | Extra charges due to late return, etc. | Default: 0, minimum: 0 |
| returnDetails.notes | String | Notes about the return | Optional |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

| maintenanceType | String | Type of maintenance | Required, must be one of: 'routine', 'repair', 'inspection', 'cleaning', 'upgrade' |
| status | String | Maintenance status | Required, must be one of: 'scheduled', 'in-progress', 'completed', 'cancelled', 'postponed' |
| scheduledDate | Date | When maintenance is scheduled | Required |
| completedDate | Date | When maintenance was completed | Optional, required if status is 'completed' |
| technician | ObjectId | User performing maintenance | Optional, must exist in Users collection if provided |
| description | String | Description of maintenance | Required, trimmed |
| issues | Array[Object] | Issues to address | Default: empty array |
| issues[].category | String | Category of issue | Required |
| issues[].description | String | Description of issue | Required |
| issues[].severity | String | Severity level | Required, must be one of: 'low', 'medium', 'high', 'critical' |
| issues[].resolved | Boolean | Whether issue was resolved | Default: false |
| parts | Array[Object] | Parts used in maintenance | Optional |
| parts[].name | String | Part name | Required |
| parts[].quantity | Number | Quantity used | Required, minimum: 1 |
| parts[].cost | Number | Cost per part | Required, minimum: 0 |
| laborHours | Number | Hours spent on maintenance | Optional, minimum: 0 |
| laborCost | Number | Cost of labor | Optional, minimum: 0 |
| totalCost | Number | Total maintenance cost | Optional, minimum: 0, calculated if not provided |
| notes | String | Additional notes | Optional |
| recommendations | String | Future maintenance recommendations | Optional |
| nextMaintenanceDate | Date | Recommended date for next service | Optional |
| images | Array[String] | URLs to maintenance images | Default: empty array |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

## Rating Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| userId | ObjectId | User who left the rating | Required, must exist in Users collection |
| entityType | String | Type of entity being rated | Required, must be one of: 'bike', 'station', 'route', 'service' |
| entityId | ObjectId | ID of the rated entity | Required, must exist in the respective collection |
| rating | Number | Rating value (1-5) | Required, integer between 1 and 5 |
| title | String | Rating title | Optional |
| comment | String | Rating comment | Optional |
| images | Array[String] | URLs to rating images | Default: empty array |
| response | Object | Response to rating | Optional |
| response.userId | ObjectId | User who responded | Required if response is provided |
| response.comment | String | Response comment | Required if response is provided |
| response.date | Date | Response date | Default: current date |
| isVerified | Boolean | Whether rating is verified | Default: false |
| isPublic | Boolean | Whether rating is publicly visible | Default: true |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |

## Route Model

| Field | Type | Description | Validation Rules |
|-------|------|-------------|-----------------|
| _id | ObjectId | Unique identifier | Generated by MongoDB |
| name | String | Route name | Required, trimmed |
| description | String | Route description | Required, trimmed |
| difficulty | String | Difficulty level | Required, must be one of: 'easy', 'moderate', 'hard', 'expert' |
| distance | Number | Route distance in kilometers | Required, minimum: 0 |
| estimatedTime | Number | Estimated time in minutes | Required, minimum: 0 |
| elevation | Number | Elevation gain in meters | Required |
| path | Object | GeoJSON LineString for route | Required |
| path.type | String | GeoJSON type | Required, must be 'LineString' |
| path.coordinates | Array[Array[Number]] | Array of [longitude, latitude] points | Required |
| startPoint | Object | Starting location | Required |
| startPoint.type | String | GeoJSON type | Required, must be 'Point' |
| startPoint.coordinates | Array[Number] | [longitude, latitude] | Required |
| startPoint.name | String | Name of start location | Required |
| endPoint | Object | Ending location | Required |
| endPoint.type | String | GeoJSON type | Required, must be 'Point' |
| endPoint.coordinates | Array[Number] | [longitude, latitude] | Required |
| endPoint.name | String | Name of end location | Required |
| waypoints | Array[Object] | Key points along route | Default: empty array |
| waypoints[].type | String | GeoJSON type | Required, must be 'Point' |
| waypoints[].coordinates | Array[Number] | [longitude, latitude] | Required |
| waypoints[].name | String | Waypoint name | Required |
| waypoints[].description | String | Waypoint description | Optional |
| pointsOfInterest | Array[Object] | Points of interest near route | Default: empty array |
| pointsOfInterest[].type | String | GeoJSON type | Required, must be 'Point' |
| pointsOfInterest[].coordinates | Array[Number] | [longitude, latitude] | Required |
| pointsOfInterest[].name | String | POI name | Required |
| pointsOfInterest[].description | String | POI description | Optional |
| pointsOfInterest[].category | String | POI category | Required |
| terrain | Array[String] | Types of terrain | Default: empty array |
| bestSeasons | Array[String] | Best seasons for route | Default: empty array, must be one of: 'spring', 'summer', 'fall', 'winter' |
| tags | Array[String] | Route tags | Default: empty array |
| imageUrls | Array[String] | URLs to route images | Default: empty array |
| createdBy | ObjectId | User who created the route | Required, must exist in Users collection |
| isPublic | Boolean | Whether route is publicly visible | Default: true |
| ratings | Array[Object] | User ratings | Default: empty array |
| ratings[].userId | ObjectId | User who left the rating | Required |
| ratings[].rating | Number | Rating value (1-5) | Required, between 1 and 5 |
| ratings[].comment | String | Rating comment | Optional |
| ratings[].date | Date | Date of the rating | Default: current date |
| averageRating | Number | Average of all ratings | Default: 0, calculated based on ratings |
| createdAt | Date | Timestamp when record was created | Automatically set |
| updatedAt | Date | Timestamp when record was last updated | Automatically set |
