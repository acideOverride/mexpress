# MontPC CRM Documentation

This directory contains documentation for the MontPC CRM project, organized by development lifecycle phases.

## Directory Structure

```
/docs/montpc_crm/
├── planning/             # Planning and requirements
│   ├── roadmap/          # Overall project roadmap
│   ├── requirements/     # Detailed requirements
│   └── brq/              # Business requirement queries
│
├── design/               # Design documentation 
│   ├── architecture/     # System architecture
│   ├── api/              # API design
│   └── ui/               # UI/UX design
│
├── implementation/       # Implementation guides
│   ├── frontend/         # Frontend implementation
│   ├── backend/          # Backend implementation
│   └── infrastructure/   # Infrastructure setup
│
├── testing/              # Testing documentation
│   ├── test-plans/       # Test plans by feature
│   └── results/          # Test result summaries
│
└── milestones/           # Milestone tracking
    ├── current/          # Active milestones
    └── completed/        # Completed milestones
```

## Documentation Guidelines

- All documentation should follow the established naming convention
- BRQs use the format: `[PROJ]-[YEAR]-[NUM]-[COMPONENT]-description.md`
- Keep documentation focused on a single topic
- Cross-reference related documents
- Update milestone tracking when requirements are completed
