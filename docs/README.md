# mExpress Documentation

This repository contains documentation for the mExpress ecosystem.

## Directory Structure

- **common/**: Cross-project standards and references
  - **standards/**: Development standards
  - **reference/**: Reference information (BRQ mapping, etc.)
  - **architecture/**: Common architectural patterns

- **mexpress/**: Foundation layer documentation
  - **architecture/**: Core architecture decisions
  - **features/**: Feature specifications
  - **api/**: API documentation

- **montpc_crm/**: MontPC CRM project documentation
  - **architecture/**: Project-specific architecture
  - **features/**: Project features
  - **integrations/**: External integrations

- **resources/**: Supporting resources
  - **agents/**: Agent role definitions

- **archive/**: Legacy documentation (for reference only)

## How to Use This Documentation

1. Start with the common standards to understand development guidelines
2. Review project-specific architecture for design decisions
3. Consult feature documentation for implementation details

## Documentation Standards

All documentation follows the formats defined in [common/standards/A_foundation.md](common/standards/A_foundation.md).
