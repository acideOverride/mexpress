TEMPLATE ORGANIZATION:

1. General Templates
   a. Session Template (session-template.md)
      - Base template for all research sessions
      - Common fields and structures
      - Basic documentation requirements
      Usage: Reference for creating specific templates

2. Research-Specific Templates
   a. Interview Template (interview-template.md)
      Purpose: User interviews and discussions
      Focus: Qualitative data collection
      Usage: All user interview sessions
      Storage: /interviews/{date}_{participant-id}/

   b. Usability Test Template (usability-test-template.md)
      Purpose: Task-based testing
      Focus: Quantitative and qualitative data
      Usage: All usability testing sessions
      Storage: /usability-tests/{date}_{participant-id}/

   c. Card Sort Template (card-sort-template.md)
      Purpose: Information architecture research
      Focus: Organizational preferences
      Usage: All card sorting sessions
      Storage: /card-sorting/{date}_{participant-id}/

   d. Prototype Test Template (prototype-test-template.md)
      Purpose: Interface design validation
      Focus: Interaction and design feedback
      Usage: All prototype testing sessions
      Storage: /prototypes/{date}_{participant-id}/
