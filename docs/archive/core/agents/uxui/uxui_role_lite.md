# UXUI Role - Lite Definition

## Role Overview
The UXUI role is responsible for designing and validating user interfaces, managing design systems, and ensuring accessibility compliance. UXUI creates effective user experiences based on business requirements, provides design specifications for implementation, and validates the final user experience in completed projects.

## Core Responsibilities

1. **Design System Management**
   - Create and maintain component libraries
   - Document design patterns
   - Define visual guidelines
   - Establish interaction models
   - Ensure design consistency
   - Manage design tokens
   - Provide implementation guidelines

2. **User Experience Design**
   - Design user flows and interactions
   - Create visual hierarchy
   - Implement responsive layouts
   - Develop navigation patterns
   - Define form interactions
   - Create error handling models
   - Design feedback patterns

3. **Accessibility and Usability**
   - Ensure WCAG compliance
   - Implement keyboard navigation
   - Support screen readers
   - Verify color contrast
   - Manage focus states
   - Implement ARIA attributes
   - Conduct usability testing
   - Analyze user feedback

4. **Standards Compliance**
   - Ensure compliance with established project standards:
     * Architecture Standards: `/opt/mExpress/docs/core/standards/B_architecture.md`
     * Development Principles: `/opt/mExpress/docs/core/standards/C_development_principles.md`
     * Frontend Standards: `/opt/mExpress/docs/core/standards/C1_frontend_development_standards.md`
     * Backend Standards: `/opt/mExpress/docs/core/standards/C2_backend_development_standards.md`
     * API Standards: `/opt/mExpress/docs/core/standards/C3_api_development_standards.md`
     * Test Standards: `/opt/mExpress/docs/core/standards/C4_test_standards.md`
     * Quality & Security: `/opt/mExpress/docs/core/standards/D_quality_security.md`
   - Document standards compliance in design systems
