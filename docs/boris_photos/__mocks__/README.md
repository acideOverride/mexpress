# Boris Art Gallery Portal - Mockup

This is a mockup for a stunning, futuristic art gallery portal for Boris, a digital artist. The portal focuses on showcasing his artwork while providing e-commerce capabilities to increase sales.

## Structure

The mockup follows a clean separation of concerns with HTML, CSS, and JavaScript:

- `index.html` - Main structure and content
- `css/styles.css` - All styling and animations
- `js/main.js` - Interactive functionality
- `js/three.min.js` - Placeholder for Three.js library (for 3D gallery)

## Features

1. **Futuristic Design Elements**
   - Glitch text effects
   - Neon color scheme
   - Floating abstract shapes
   - Gradient overlays and backdrop filters

2. **Gallery Showcase**
   - Featured works section
   - Collections grouping
   - 3D virtual gallery preview
   - Hover effects and transitions

3. **Artist Promotion**
   - About the artist section
   - Social media integration
   - Visual emphasis on the artwork

4. **E-commerce Functionality**
   - Shopping cart implementation
   - Product displays with pricing
   - Newsletter subscription for updates

5. **Responsive Design**
   - Mobile-friendly navigation
   - Flexible layouts for all screen sizes
   - Optimized display of gallery items

## Usage

To view the mockup:
1. Open `index.html` in a modern web browser
2. Navigate through the different sections
3. Test interactive elements like the navigation and 3D preview
