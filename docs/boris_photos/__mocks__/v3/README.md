# Boris Photography Portal - V3 Mockup

This is a stunning, modern photography portal design for Boris that focuses on creating a seamless, immersive experience that showcases the artwork in a visually striking way.

## Design Concept

This design combines contemporary aesthetics with interactive elements to create a unique visual experience:

- **Modern Minimalism**: Clean layouts with purposeful design elements that put the focus on the photography
- **Interactive Experience**: Custom cursor, smooth transitions, and subtle animations create an engaging journey
- **Immersive Visuals**: Full-screen hero slider, parallax effects, and thoughtfully presented galleries
- **Futuristic UI Elements**: Subtle glow effects, elegant typography, and modern color scheme
- **Dark/Light Mode**: Theme toggle for personalized viewing experience

## Structure

The mockup follows a clean separation of concerns:

- `index.html` - Core structure and content
- `css/styles.css` - Comprehensive styling with variables for theming
- `js/main.js` - Interactive features and animations

## Key Features

1. **Immersive Experience**
   - Custom cursor with interactive states
   - Stylish page loader with progress animation
   - Smooth scrolling and reveal animations
   - Dark/light theme toggle

2. **Content Presentation**
   - Full-screen hero slider with dynamic text animations
   - Interactive gallery with filtering capabilities
   - Project showcase with thumbnail navigation
   - Studio presentation with statistics and services

3. **Professional Showcase**
   - Vision statement section with parallax background

4. **E-commerce Integration**
   - Gallery items with purchase options
   - Detailed product modal with size and frame selection

5. **Mobile Optimization**
   - Responsive design for all screen sizes
   - Touch-friendly navigation
   - Optimized content display for mobile devices
