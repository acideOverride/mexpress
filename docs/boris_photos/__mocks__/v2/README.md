# Boris Photography Portal - V2 Mockup

This is a clean, elegant mockup for a fine art photography portal for Boris. The design focuses on showcasing the artwork through a minimalist, sophisticated interface that emphasizes the photography rather than flashy design elements.

## Structure

The mockup follows a clean separation of concerns with HTML, CSS, and JavaScript:

- `index.html` - Main structure and content
- `css/styles.css` - All styling and animations
- `js/main.js` - Interactive functionality

## Features

1. **Elegant Design Language**
   - Clean typography with serif/sans-serif pairing
   - Neutral color palette with subtle gold accent
   - Generous whitespace to showcase photography
   - Sophisticated, minimalist layout

2. **Portfolio Showcase**
   - Featured portfolio grid with hover effects
   - Thematic collections slider
   - Exhibition calendar
   - Limited edition print store with filtering

3. **Artist Promotion**
   - Refined about section with education and exhibition history
   - Professional contact form
   - Social media integration

4. **E-commerce Functionality**
   - Print store with filtering options
   - Quick view modal with sizing and framing options
   - Shopping cart with item management
   - Checkout integration

5. **Responsive Design**
   - Mobile-friendly navigation
   - Flexible layouts for all screen sizes
   - Optimized grid layouts for different devices

## Usage

To view the mockup:
1. Open `index.html` in a modern web browser
2. Navigate through the different sections
3. Test interactive elements like the portfolio filters and product modals
