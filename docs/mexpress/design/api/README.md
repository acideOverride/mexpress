# mExpress API Documentation

This directory contains documentation for the mExpress APIs.

## Structure

- **endpoints/**: Documentation for individual API endpoints
- **schemas/**: Data schemas and models
- **examples/**: Example API requests and responses

## API Standards

API design follows the standards defined in [/opt/mExpress/docs/common/standards/C3_api_development_standards.md](/opt/mExpress/docs/common/standards/C3_api_development_standards.md).
