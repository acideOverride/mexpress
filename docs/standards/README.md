# mExpress Common Standards

This directory contains the core standards that apply across all projects in the mExpress ecosystem.

## Standards Index

- **A_foundation.md**: Base project structure and organization
- **B_architecture.md**: Architecture standards and patterns
- **C_development_principles.md**: Cross-cutting development principles
- **C1_frontend_development_standards.md**: Frontend-specific standards
- **C2_backend_development_standards.md**: Backend-specific standards
- **C3_api_development_standards.md**: API design and implementation standards
- **C4_test_standards.md**: Testing standards and practices
- **D_quality_security.md**: Quality assurance and security standards
- **E_agent_standards.md**: Standards for working with AI agents

These standards provide a consistent foundation for all development work in the mExpress ecosystem.
