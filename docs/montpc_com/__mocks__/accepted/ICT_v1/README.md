# MontPC Interactive Configuration Tool (ICT) - v1

This is a mock-up implementation of a step-by-step configurator for MontPC repair services. The configurator guides customers through selecting their device details and repair requirements without overwhelming them with all options at once.

## Features

- Step-by-step configuration process:
  1. Device Type selection
  2. Brand selection
  3. Series selection
  4. Model selection
  5. Issue selection
  6. Quality Preference selection
- Dynamic loading of options based on previous selections
- Clean, fashionable UI design with "The Devil Wears Prada meets Sanrio" aesthetic
- Mobile-responsive design
- Dark mode support
- Interactive summary with pricing breakdown
- Add-on options for additional services

## Implementation Details

This mock-up includes:

- HTML structure for the configurator UI
- CSS styling with responsive design
- JavaScript for the interactive experience
- Mock product database and pricing model

## Usage

Simply open the `index.html` file in any modern web browser to see the interactive configurator in action.

## Note about Images

This mock-up uses SVG icons directly in the HTML/CSS rather than separate image files for simplicity. In a production implementation, product images would be included for each device option.
