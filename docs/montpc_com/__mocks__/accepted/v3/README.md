# MontPC Website V3 - "Devil Wears Prada meets Sanrio"

## Design Concept

This design concept blends the sophistication and elegance of high fashion (inspired by "The Devil Wears Prada") with the playful cuteness of Sanrio characters. The result is a website that feels premium and professional while incorporating delightful, whimsical elements that create a memorable user experience.

### Key Design Elements

1. **Fashion-Forward Typography**
   - Elegant Playfair Display for headings
   - Clean Poppins for body text
   - Italic accents for fashion magazine feel

2. **Color Palette**
   - Primary: Orange (#FF8500) - Brand color
   - Fashion Accent: Hot Pink (#FF3E82) - Fashion magazine inspired
   - Cute Accents: Soft blue, yellow, and pink pastels - Sanrio inspired
   - Clean neutrals: Whites, grays, and blacks

3. **Fashion Magazine Visual Elements**
   - Elegant section headings with decorative underlines
   - Asymmetrical layouts
   - High contrast text
   - Italicized quotes and emphasis
   - Clean white space

4. **Cute Sanrio-inspired Details**
   - Floating bubble accents with pastel colors
   - Rounded corners throughout
   - Playful animations
   - Small decorative elements on cards and sections
   - Soft shadows and gentle transitions

5. **Interactive Elements**
   - Custom cursor effect (desktop only)
   - Magnetic hover effects on cards
   - Smooth reveal animations on scroll
   - Glare animations on service cards
   - Playful micro-interactions

6. **Thematic Sections**
   - "Signature Services" presented like a fashion collection
   - "The Atelier" for about section
   - "Curated Process" for repair steps
   - "Portfolio" for work showcase
   - "Testimonials" styled like magazine quotes

## User Experience

This design aims to convey that MontPC isn't just a repair shop but a premium tech service "boutique" where devices are treated with the same care and attention as haute couture. The cute elements add a touch of approachability and memorability to what could otherwise be a typical tech repair website.

### Target Audience Appeal

- **Fashion-Conscious Users**: Will appreciate the sophisticated layout and attention to detail
- **Young Adults**: Will connect with the playful, cute elements and social media aesthetic
- **Tech Enthusiasts**: Will find the service information clear and the technical elements engaging

## Technical Features

1. **Theme Toggle**
   - Light mode (default) and dark mode options
   - Preference saved to localStorage

2. **Responsive Design**
   - Mobile-first approach
   - Adaptive layouts for all screen sizes
   - Custom mobile navigation

3. **Advanced CSS Features**
   - CSS Variables for theming
   - Flexbox and Grid layouts
   - CSS animations and transitions
   - Pseudo-elements for decorative details

4. **JavaScript Interactions**
   - Custom cursor (desktop)
   - Magnetic hover effects
   - Scroll reveal animations
   - Testimonial slider
   - Form validation

## Design References

This design draws inspiration from:
- High-fashion magazine layouts (Vogue, Elle)
- "The Devil Wears Prada" aesthetic (clean, elegant, slightly intimidating)
- Sanrio character designs (Hello Kitty, My Melody) - soft colors, rounded shapes
- Modern tech websites with a focus on premium service

## Implementation Notes

The design is implemented with:
- HTML5 semantic structure
- CSS3 with modern features (variables, grid, animations)
- Vanilla JavaScript for interactions
- SVG icons for crisp, scalable visuals
- Custom animations for enhanced engagement

All interactions gracefully degrade on devices that don't support them, ensuring a good experience across all platforms.
