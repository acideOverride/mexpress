# Giandra Photos - Maquette du Portail Client

Ce répertoire contient la maquette front-end pour le portail client de Giandra Photos. Giandra Photos est une plateforme où une artiste peut présenter, vendre et louer ses œuvres photographiques, ainsi que notifier ses clients des événements et expositions à venir.

## Aperçu

La maquette présente un design épuré, artistique et moderne avec un accent sur la présentation de la photographie de manière élégante. L'interface vise à créer une expérience visuelle harmonieuse et pure qui complète les œuvres d'art.

## Fichiers

- `gallery-portal.html` - La structure HTML principale pour le portail client
- `gallery-portal.css` - Le style pour le portail client avec support thème clair/sombre
- `gallery-portal.js` - Les fonctionnalités JavaScript pour les éléments interactifs

## Principales Fonctionnalités Présentées

1. **Vitrine de Galerie** - Collections en vedette avec élégants effets au survol
2. **Services d'Art** - Options d'achat, de location et de commande personnalisée
3. **Recherche d'Œuvres** - Outil interactif pour trouver des œuvres selon le style, la couleur, l'espace et le budget
4. **Calendrier d'Événements** - Expositions et événements à venir avec fonctionnalité de réservation
5. **Témoignages de Collectionneurs** - Preuve sociale de clients précédents
6. **Inscription à la Newsletter** - Rester connecté avec l'artiste
7. **Design Responsive** - Mise en page adaptée aux mobiles

## Principes de Design

- **Propre & Harmonieux** - Design minimaliste qui permet aux œuvres d'art de se démarquer
- **Typographie Élégante** - En-têtes serif avec texte sans-serif pour la lisibilité
- **Palette de Couleurs Sophistiquée** - Pourpres et verts doux comme couleurs primaires
- **Espaces Blancs Généreux** - Espacement autour des éléments de contenu
- **Animations Subtiles** - Transitions douces et effets au survol
- **Thème Clair/Sombre** - Support pour les deux modes de visualisation

## Notes d'Implémentation

Cette maquette utilise :
- HTML/CSS/JavaScript pur (pas de frameworks)
- Variables CSS pour les thèmes
- Flexbox et Grid pour les mises en page
- Techniques de design responsive
